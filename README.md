# Signature Detector Batch v17.0
BUILD 17.0 · 2026-08-13

## 이번 버전의 목적

파일을 새로 저장하지 않습니다.

처리 순서:

1. PDF/JPG/PNG 업로드
2. 대표 페이지를 작은 해상도로 OCR하여 문자 방향 확인
3. 정방향이면 회전 작업 생략
4. 90/180/270도 보정이 필요하면 화면에
   - 원본 방향
   - OCR 문자 기준 정방향
   을 나란히 표시
5. 이후의 서명영역 탐지는 정방향 좌표계에서 실행
6. 원본 정방향 페이지에 탐지영역을 노란 테두리로 표시
7. 같은 영역을 약 40px 마진과 함께 크게 확대
8. 확대 영역에서 그린 획을 원본 정방향 페이지의 같은 위치에도 즉시 반영

## 방향 판정 속도

정상 경로:
- 대표 페이지 최대 680px
- Tesseract rotateAuto OCR 1회
- 확신도가 충분하면 즉시 종료

애매한 경우에만:
- 최대 520px probe
- 0/90/180/270 저해상도 OCR 비교

방향 보정을 위해 모든 PDF 페이지를 미리 고해상도로 렌더하거나
새 PDF/JPG/PNG 파일을 생성하지 않습니다.

실제 페이지는 서명 탐지 시 필요한 순간에만 회전 렌더링합니다.

## 서명 탐지

기존 v15/v16 탐지 기준을 유지합니다.

- 숫자가 입력되지 않은 년 / 월 / 일
- 매수인
- 서명 / 서명 또는 인 / (인)
- 확인합니다 / 본인은 / 사실은 보조 문맥

1차 페이지 OCR에서 강한 후보가 나오면 즉시 종료하며,
실패할 때만 가장 가능성이 높은 페이지 최대 2개를 보정 OCR합니다.
