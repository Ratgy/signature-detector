# Signature Detector Batch v16.0
BUILD 16.0 · 2026-08-13

## 신규 전처리: OCR 문자 방향 정규화

서명 탐지를 시작하기 전에 문서 방향을 먼저 정규화합니다.

1. 대표 페이지를 저해상도로 렌더합니다.
2. Tesseract.js `rotateAuto: true`로 OCR 기반 자동 회전을 수행하고 `imageColor` 결과를 받습니다.
3. 자동 회전 결과와 0/90/180/270 후보를 비교해 실제 보정 각도를 계산합니다.
4. 결과가 애매할 때만 작은 OCR probe 4방향 비교를 fallback으로 사용합니다.
5. 보정 각도를 문서 전체에 적용합니다.
6. 보정된 문서를 같은 확장자로 `_upright` 파일로 저장할 수 있습니다.
   - JPG → JPG
   - PNG → PNG
   - PDF → PDF (스캔 페이지를 정방향 이미지 PDF로 재생성)
7. 이후 서명영역 탐지와 linked signature editor는 정방향 문서를 기준으로 실행됩니다.

## 성능 원칙

- 정상 방향이면 문서를 다시 만들지 않고 원본을 그대로 사용합니다.
- 일반 경로는 auto-rotate OCR 1회입니다.
- 방향 신뢰도가 낮을 때만 0/90/180/270 추가 검증을 합니다.
- PDF는 문서 전체가 같은 회전으로 저장된 스캔이라는 전제로 대표 페이지에서 방향을 한 번 판정하고 전 페이지에 적용합니다.

## 기준 방향

최종 기준은 사용자가 화면에서 읽을 때 한글 문장이 좌→우로 정상적으로 읽히는 정방향입니다.
