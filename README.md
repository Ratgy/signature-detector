# Signature Detector Fast v5

목표:
1. v4보다 빠르게
2. 위치 규칙 대신 "날짜 + 서명 계열 텍스트의 근접성"으로 정확하게
3. 확대된 원본 스캔 위에 날짜/서명을 직접 입력
4. 분석 중 progress가 멈춰 보이지 않게 1% 단위로 지속 증가

탐지 전략:
- 모든 페이지 0° 저해상도 OCR 1회
- 가장 가능성 높은 1페이지만 회전 fallback
- `연월일 / 년월일 / 년·월·일`과 `매수인 / 서명 / (인) / 성명 / 고지자`가 가까울 때만 후보
- 정밀 word OCR은 선택된 1페이지/1각도에서 1회
- 후보는 날짜와 서명 앵커를 감싸는 compact block

Progress:
- 실제 작업 단계가 target progress를 갱신
- UI는 70ms마다 1%씩 증가
- 긴 OCR 호출 중에도 최근 milestone보다 최대 +4%까지 천천히 증가
- 작업 완료 전에는 96%를 넘지 않음
- 실제 완료 후 97→100%를 1% 단위로 마무리

현재 한계:
- "입력 완료"는 아직 PDF 바이너리 자체에 쓰지는 않음
- 다음 단계에서 normalized 좌표 + canvas annotation을 실제 PDF export에 합성 가능
