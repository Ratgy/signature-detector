# Signature Detector v24.0

Android / GitHub / Vercel 배포용 웹 프로젝트입니다.

## 포함 기능
- PDF / JPG / PNG 업로드
- OCR 기반 문서 방향 보정
- 1차 서명영역 후보 탐지
- 후보영역 확대 후 2차 재탐지
- 최종 서명영역 Crop
- 모바일 확대 서명 Canvas
- 확대 Canvas에서 작성한 획을 원본 동일 좌표에 반영

## GitHub에 올릴 파일
현재 ZIP 안의 파일들을 저장소 최상위에 그대로 업로드하면 됩니다.

## 배포
Vercel에서 GitHub 저장소를 Import하면 Vite 프로젝트로 자동 인식됩니다.

Mac 전용 실행 스크립트는 포함하지 않습니다.
