# Signature Detector v15.0
BUILD 15.0 · 2026-08-13

## 목표
스캔 PDF/JPG/PNG에서 실제 사용자가 작성해야 하는 빈 서명행을 찾습니다.

- 숫자가 없는 `년 / 월 / 일`
- `매수인`
- `서명 / 서명 또는 인 / (인)`
- 또는 저화질 촬영본에서 `확인 문장 + 바로 아래 빈 년월일 행`

## 속도 개선
v14의 페이지별 4~8개 strip contact sheet를 기본 경로에서 제거했습니다.

1. 페이지 전체 OCR 1회
2. 성공 시 즉시 종료
3. 실패할 때만 좌/우 논리페이지 또는 상/하 2개 확대영역을 한 contact sheet로 묶어 OCR 1회

즉 정상 문서는 페이지당 OCR 1회입니다.

## JPG/PNG 개선
첫 OCR은 `PSM.SINGLE_BLOCK`을 사용해 표 안의 `년 월 일 / 매수인 / 서명` 행을 한 줄로 유지합니다.
실패 때만 확대 분할 + adaptive threshold + `PSM.SPARSE_TEXT`를 사용합니다.

OCR이 `매수인`을 놓쳐도 다음 구조를 fallback으로 인정합니다.

- 강한 `확인합니다 / 본인은 / 사실` 문맥
- 바로 아래 숫자가 없는 `년 월 일` 행

일반 본문만으로는 결과를 만들지 않습니다.

## 편집 UI
- 원본 페이지를 보여줍니다.
- 실제 서명영역은 `#FAC729` 노란 테두리로 표시합니다.
- 서명영역은 약 40px margin을 포함해 크게 확대합니다.
- 모바일에서 확대 서명영역은 viewport 좌우 20px까지 채웁니다.
- 확대영역에서 손가락/펜으로 쓴 stroke는 원본 페이지의 동일 좌표에 실시간 반영됩니다.
- 작성 초기화 제공.

## 진행률
모든 progress update는 `max(current, next)`를 사용하므로 퍼센트가 뒤로 갈 수 없습니다.
