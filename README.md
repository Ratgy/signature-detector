# Signature Detector Batch v9

실패 원인 수정 버전.

## v8이 전부 실패한 주된 이유

1. `확인합니다` OCR을 너무 강하게 요구함
   - 작은 스캔에서는 `확인`, `확인합니`, `화인합니다` 등으로 깨질 수 있음.
2. 실제 목표 블록에는 서로 다른 확인/서명 영역이 2개 이상 존재할 수 있음.
   - 위쪽: 검사자/고지자 날짜 및 도장 — 이미 작성된 영역
   - 아래쪽: `본인은 ... 확인합니다` + 빈 `년 월 일 / 매수인 / 서명 또는 인`
3. `년 / 월 / 일`이 OCR에서 한 줄이 아니라 각각 독립 token으로 분리될 수 있음.
4. 저해상도 정밀 OCR로 아주 작은 `매수인`, `서명 또는 인`을 놓칠 수 있음.

## v9 판정 전략

목표는 "빈 매수인 서명 블록"입니다.

우선 순위:
- `확인` 문맥 (`본인은`, `사실`, `확인`을 부분적으로 허용)
- 그 아래 0~20% 이내
- `년 / 월 / 일`
- `매수인`
- `서명 또는 인`
- 날짜와 매수인/서명이 같은 행 또는 인접행
- 이미 YYYY/MM/DD가 채워진 날짜는 감점
- 여러 후보가 있으면 더 아래에 있는 유효 buyer acknowledgement block 가점

추가:
- OCR line 검출 실패 시 개별 `년`, `월`, `일` token 좌표를 직접 조합.
- 정밀 렌더 해상도를 1650 → 2200px로 올려 작은 한글 라벨 인식률 개선.
- 자동 회전 없음.
