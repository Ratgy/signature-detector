# Signature Detector Batch v7

## 고정 탐지 전략

서명영역 후보는 아래 세 종류가 **서로 가까이 있을 때만** 생성됩니다.

1. `확인합니다`
2. `연월일`, `년월일`, 또는 `년 / 월 / 일`
3. `서명`, `(인)`, `인`, `성명`, `매수인`

단일 키워드만으로 후보를 만들지 않습니다.

## 입력 지원

- PDF
- JPG / JPEG
- PNG
- 한 번에 최대 5개

## 회전 처리

각 페이지/이미지를 0°, 90°, 180°, 270°로 저해상도 OCR해서
`확인합니다 + 날짜 + 서명` 문맥과 한글 인식량이 가장 높은 방향을 선택합니다.

정밀 OCR과 결과 Crop은 그 방향으로 다시 렌더링하며,
결과 원본 미리보기도 선택된 방향으로 똑바로 표시됩니다.

## 검수 UI

- 탐지된 서명영역 대형 Crop
- 실제 매칭된 `확인 / 날짜 / 서명` OCR 문자열
- 자동 회전된 원본
- 처리시간
- 정확함 / 일부 포함 / 틀림 / 탐지 실패
- Exact / Usable 통계
