# Signature Detector Fast v4

변경점:
- "최종행" 가정 제거
- 페이지 상/중/하 3개 band를 빠르게 검색
- 모든 페이지는 0° 우선
- 방향이 애매할 때만 선택된 후보 페이지를 90/270/180 추가 검사
- 정밀 OCR은 최종 1개 페이지 + 1개 band에서만 실행
- 날짜 앵커(연월일 / 년월일 / 년·월·일)와 서명 앵커(매수인 / 서명 / (인) / 성명)의 공간 관계로 영역 계산
- 가로선 픽셀 스캔을 추가해 빈 작성선 주변을 보조 탐지
- 확대된 문서 이미지 위에 날짜 직접 입력
- 확대된 문서 이미지 위에 손가락 서명
- 자유필기 모드
- 진행률은 UI에서 1% 단위로 부드럽게 증가
- 처리시간 표시

주의:
현재 "입력 완료"는 화면상 주석까지만 반영됩니다.
다음 단계는 같은 normalized 좌표를 이용해 실제 PDF 결과물에 annotation layer를 합성하는 것입니다.
