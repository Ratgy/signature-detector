# Signature Detector Batch v8

## 핵심 변경

자동 회전은 보류했습니다.

이번 탐지는 단순 키워드 근접성이 아니라 실제 예시 문서의 레이아웃 순서를 반영합니다.

1. `확인합니다` 또는 `본인은 ... 사실을 확인합니다` 같은 확인 문장 탐지
2. 그 문장과 같은 줄 또는 아래 약 20~24% 범위에서 날짜 표현 탐지
   - `연월일`
   - `년월일`
   - `년 / 월 / 일`
   - `2026년 03월 17일`
   - `2026-03-17`
3. 같은 확인 블록 안에서 서명 관련 줄 탐지
   - `서명`
   - `서명 또는 인`
   - `(인)`
   - `매수인`
   - `고지자`
   - `점검자`
4. 확인 + 날짜 + 서명 줄이 같은 로컬 영역에 들어올 때만 서명영역 후보 생성
5. 해당 세 줄을 감싸는 영역만 Crop해서 확대 표시

## 입력

- PDF
- JPG / JPEG
- PNG
- 최대 5개

## 검수

각 결과에서 실제 OCR된:
- 확인 문장
- 날짜 줄
- 서명 줄

을 함께 표시합니다.

이 정보로 탐지가 실패했을 때 어느 단계가 문제인지 확인할 수 있습니다.
