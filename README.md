# Signature Detector Batch v18.0
BUILD 18.0 · 2026-08-13

## 방향 판정 핵심

방향 판단의 1순위 기준을 OCR 텍스트 중심점으로 변경했습니다.

1. 방향 확인용 대표 페이지를 최대 720px로 렌더
2. 원본 방향 그대로 `kor` OCR 1회
3. OCR이 같은 글줄로 인식한 연속 단어 bbox의 중심점을 계산
4. 앞 단어 중심 → 다음 단어 중심의 directed vector angle 계산
5. 벡터를 0 / 90 / 180 / 270도 네 범주에 투표
6. 각 범주의 ±18도 안에 들어온 벡터만 유효표로 인정
7. 최소 3개 유효 벡터 + 우세 범주 56% 이상 조건
8. 중심각이 충분히 명확하면 추가 방향 OCR 없이 즉시 결정

예:
- 중심각 4° → 문자 0° → 문서 회전 없음
- 중심각 87° → 문자 90° 범주 → 문서 270° 회전
- 중심각 176° → 문자 180° 범주 → 문서 180° 회전
- 중심각 268° → 문자 270° 범주 → 문서 90° 회전
- 중심각 32° → quarter-turn 범주 밖 → 자동 회전하지 않고 fallback 검증

## 민감도

`ANGLE_TOLERANCE_DEG = 18`

즉:
- 0° 범주: 342°~360° 또는 0°~18°
- 90° 범주: 72°~108°
- 180° 범주: 162°~198°
- 270° 범주: 252°~288°

스캔이 몇 도 비뚤어진 정도로는 90도 단위 회전을 잘못 적용하지 않습니다.

## fallback

OCR 중심벡터가 3개 미만이거나,
우세 범주가 56% 미만이거나,
대부분의 각도가 quarter-turn ±18° 밖이면:

1. 기존 Tesseract rotateAuto 보조검증 1회
2. 그것도 불명확할 때만 520px 이하 0/90/180/270 OCR 비교

따라서 명확한 일반 문서는 방향 판정을 위해 4회 OCR하지 않습니다.

## 이후 서명 로직

방향 보정은 화면/렌더 좌표계에만 적용하고 파일은 저장하지 않습니다.

보정 후 기존 서명 탐지:
- 숫자가 없는 년 / 월 / 일
- 매수인
- 서명 / 서명 또는 인 / (인)
- 확인합니다 / 본인은 / 사실은 보조 문맥

원본 정방향 페이지에는 노란색 테두리,
아래에는 동일 영역을 약 40px 마진으로 확대하며,
확대 영역에서 작성한 획은 원본 정방향 페이지의 동일 좌표에 반영됩니다.
